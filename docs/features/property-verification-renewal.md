# 매물 재인증 안내와 갱신

## 정책

- 인증 유효기간은 승인 시점부터 30일입니다.
- 만료 7일 전부터 재인증 안내를 한 번 발행합니다.
- 유효 인증의 재인증 신청은 만료 7일 전부터 허용합니다.
- 재인증 심사 중과 반려 후에는 기존 인증을 원래 만료일까지 유지합니다.
- 재인증이 승인되면 이전 인증 요청을 대체하고 승인 시점부터 30일을 다시 계산합니다.
- 실제 만료 시 검색 노출 제외는 기존 인증 만료 배치가 처리합니다.

## 알림 흐름

1. 배치가 7일 이내 만료 예정이며 미안내 상태인 인증을 최대 100건 조회합니다.
2. 매물과 인증 행을 잠근 후 현재도 안내 대상인지 다시 확인합니다.
3. `renewal_notified_at`을 기록하고 감사 이벤트를 저장합니다.
4. 커밋 후 `PROPERTY_VERIFICATION_RENEWAL_DUE` 이벤트를 Kafka에 직접 발행합니다.

이벤트에는 매물 ID, 인증 ID, 신청 회원 ID, 인증 유형, 만료 시각만 포함하며
증빙 파일이나 개인정보 원문은 포함하지 않습니다.

## 전달 보장 제한

Outbox를 사용하지 않는 현재 구조에서는 DB 커밋 후 Kafka 전송 실패 시 이벤트가
유실될 수 있습니다. 중복 안내는 방지하지만 완전한 재전송 보장은 제공하지 않습니다.

## DB 및 설정

- DDL: `database/schema/013_add_property_verification_renewal_notification.sql`
- 실행 주기 환경 변수:
  `PROPERTY_VERIFICATION_RENEWAL_NOTIFICATION_FIXED_DELAY_MS`
- 기본 실행 간격: 15분
